# Sabor Andino Frontend

Sitio público y panel administrativo desarrollados con Angular.

## Ejecutar

```bash
npm install
npm start
```

Abre `http://localhost:4200`.

El backend debe estar activo en `http://localhost:8080` y la URL se configura en:

```text
src/app/core/api/api.config.ts
```

El diseño incluye vistas adaptables para escritorio, tableta y celular.
